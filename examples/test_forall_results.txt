================================================================================
NOTES ON FORALL SEMANTICS
================================================================================

Key points:
1. FORALL r. φ(r) means φ must be true for ALL values of r in the active domain
2. Active domain = all constants that appear in ANY position of ANY predicate at that timestamp
3. Single value case: If only one r value exists, FORALL is satisfied if φ(r) is true
4. Empty case: FORALL over empty domain is vacuously true (no counterexamples)
5. PDT structure: The formula returns a PDT over free variables (x,y,...) where each path
   represents a variable binding. A path is TRUE if FORALL r. φ holds for that binding.

Implementation:
- FORALL x. φ is parsed as: NOT EXISTS x. NOT φ
- This uses De Morgan's law: ∀x.φ ≡ ¬∃x.¬φ
- No separate ForallFormula class needed
- Works correctly with nested quantifiers and temporal operators

Active Domain Semantics:
- For FORALL r. φ, r ranges over ALL constants appearing in the log at that timestamp
- This includes constants in any argument position of any predicate
- Example: If log has p(A,B) q(C,D), then active domain = {A,B,C,D}
- NOT just the values that appear where r binds in the formula
