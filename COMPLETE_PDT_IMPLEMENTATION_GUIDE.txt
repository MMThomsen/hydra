PART 1: OVERVIEW AND ARCHITECTURE
================================================================================

1.1 WHAT ARE WE BUILDING?
--------------------------
A system to monitor Metric First-Order Dynamic Logic (MFODL) formulas where:
- Each unique tuple binding gets its own monitor instance
- Monitors maintain independent state for dynamic operators
- PDT structure organizes monitors by variable bindings
- Leaf nodes store monitor copies with complete state

EXAMPLE: EXISTS x. PREV[0,5] p(x)
  Log: @0 p(Alice) @1 p(Bob) @2 p(Alice)
  
  PDT Structure:
    Root Node (partition by 'x'):
    ├─ {Alice} → Leaf(monitor_alice)  // Tracks p(Alice) over time
    └─ {Bob}   → Leaf(monitor_bob)    // Tracks p(Bob) over time
  
  Each monitor:
    - Has independent Event handle
    - Maintains buffers for dynamic operators (PREV, SINCE, etc.)
    - Evaluates metric intervals independently


1.2 KEY COMPONENTS
------------------
1. MonitorState: Wrapper for Monitor* with metadata (timestamp, verdict)
2. PDT Storage: map<int, Pdt::PdtT<MonitorState>> in Event struct
3. MonitorVisitor: Creates monitors from formulas (already exists!)
4. Pattern Matching: Variables (x,y) vs constants (Alice,5)
5. Existential Evaluation: Check if ANY monitor has true verdict


1.3 DESIGN DECISIONS
--------------------
Q: When are monitors created?
A: Lazily - when a tuple first appears in the log

Q: How are monitors initialized?
A: Using MonitorVisitor with fresh Event handle at current timestamp

Q: One PDT per predicate or per formula?
A: One PDT per predicate (shared), pattern matching handles variable order

Q: What's stored at PDT leaves?
A: MonitorState struct containing Monitor* + metadata

Q: How is state copied?
A: Monitor::clone() creates deep copy with independent Event handle

PART 2: UNDERSTANDING PDT STRUCTURE
================================================================================

2.1 PDT BASICS (from pdt.h)
---------------------------
PDT is a template-based structure:

    template <typename A>
    using PdtT = std::variant<Leaf<A>, Node<A>>;
    
    template <typename A>
    struct Leaf {
        A value;
        explicit Leaf(A v) : value(std::move(v)) {}
    };
    
    template <typename A>
    struct Node {
        std::string x;                  // Variable name
        Part::PartT<PdtT<A>> part;     // Partition: vector<pair<Setc, PdtT<A>>>
    };

Key functions:
- Pdt::isleaf(pdt): Check if node is a leaf
- Pdt::isnode(pdt): Check if node is internal
- Pdt::unleaf(pdt): Extract value from leaf
- Pdt::var(pdt): Get variable name from node
- Pdt::part(pdt): Get partition from node


2.2 PDT EXAMPLE
---------------
For p(a,f) with tuples: p(Alice,163), p(Bob,163), p(Charlie,163), p(Charlie,152)

    Root Node (partition by 'a'):
    ├─ {Alice} → Node (partition by 'f')
    │           └─ {163} → Leaf(monitor_state_copy_1)
    ├─ {Bob} → Node (partition by 'f')  
    │         └─ {163} → Leaf(monitor_state_copy_2)
    └─ {Charlie} → Node (partition by 'f')
                  ├─ {163} → Leaf(monitor_state_copy_3)
                  └─ {152} → Leaf(monitor_state_copy_4)

IMPORTANT: Each leaf contains a COPY of the current monitor state. When we update
           the PDT with new tuples, we create a new monitor copy for each new leaf.
           This preserves the state for dynamic operators - each unique tuple 
           binding gets its own independent monitor instance that maintains its
           own history for metric intervals.


2.3 PARTITION STRUCTURE
-----------------------
From Part namespace in pdt.h:

    template <typename A>
    using PartT = std::vector<std::pair<Sub, A>>;
    
    where Sub = Setc (set of domain values)

Each partition entry:
- Setc: Set of domain values (e.g., {Alice}, {Bob,Charlie})
- A: Corresponding PDT subtree for those values

Helper functions:
- Part::singleton_set(d): Create set with single domain value
- Part::trivial(a): Create partition with single universal entry
- Part::map(part, f): Map function over partition values
- Part::fold_left(part, init, f): Fold over partition

3.1 HOW MONITORS COPY STATE
----------------------------
**CRITICAL DISCOVERY**: MonitorVisitor creates monitors with independent state!

When MonitorVisitor creates a monitor:
    void visit(PrevFormula *f) {
        f->f->accept(*this);
        mon = new PrevMonitor(input_reader, 
                             input_reader->open_handle(),  // ← New Event handle
                             mon, f->from, f->to);
    }

Key: `input_reader->open_handle()` creates a FRESH Event object:
    Event *open_handle() override {
        return new Event(trie->cnt);  // Fresh event with default state
    }

This means:
- Each monitor gets its own Event handle
- Event starts at tp=-1, ts=0 (initial state)
- Independent from other monitors' events


3.2 MONITOR CLONING
-------------------
When we need to duplicate a monitor for a new tuple binding:

    Monitor* mon = visitor.get_mon();  // Original monitor
    Monitor* copy = mon->clone();      // Independent copy

Example - PrevMonitor::clone():

    Monitor *PrevMonitor::clone() {
        PrevMonitor *mon = new PrevMonitor(
            input_reader,
            handle->clone(),        // ← CLONES the Event handle!
            subf->clone(),          // ← CLONES the subformula monitor!
            from, to
        );
        mon->eof = eof;
        mon->v = v;                 // ← Copies temporal state (previous verdict)
        return mon;
    }

Event::clone() implementation:

    Event *clone() const {
        return new Event(this);  // Copy constructor
    }
    
    Event(const Event *e) 
        : pos(e->pos), ts(e->ts), tp(e->tp), eof(e->eof), 
          c(e->c), ap_cnt(e->ap_cnt), ap_lookup(e->ap_lookup) {}


3.3 WHAT GETS COPIED
--------------------
When a monitor is cloned, ALL state is duplicated:

1. Event Handle State:
   - pos: Current position in log file
   - ts: Current timestamp
   - tp: Current timepoint counter
   - eof: End-of-file flag
   - ap_lookup: Boolean vector for atom occurrences

2. Monitor-Specific State:
   PrevMonitor (metric past operator):
   - v: Optional<BooleanVerdict> (stores previous satisfaction)
   - eof: Monitor's EOF status
   
   SinceMonitor (metric past operator):
   - buf: Circular buffer of past satisfactions
   - alphas: Satisfaction intervals for metric constraints
   
   UntilMonitor (metric future operator):
   - buf_f, buf_g: Buffers for both subformulas
   - beta: Satisfaction tracking for metric constraints

3. Submonitor Copies:
   - Recursively clones all nested monitors
   - Each submonitor gets independent state


3.4 MONITOR CREATION WITH MonitorVisitor
-----------------------------------------
**KEY INSIGHT**: HYDRA already has MonitorVisitor class that creates monitors for dynamic operators!

Usage:
    Formula* f = ...;                   // Any formula
    InputReader* reader = ...;           // Log file reader
    
    MonitorVisitor visitor(reader);     // Create visitor
    f->accept(visitor);                  // Visit formula
    Monitor* mon = visitor.get_mon();   // Get created monitor

Examples from visitors.h:

    void visit(AtomFormula *f) {
        mon = new NonTempMonitor(f, input_reader, input_reader->open_handle());
    }
    
    void visit(PrevFormula *f) {
        f->f->accept(*this);  // Recursively create subformula monitor
        mon = new PrevMonitor(input_reader, input_reader->open_handle(), 
                            mon, f->from, f->to);
    }
    
    void visit(SinceFormula *f) {
        f->f->accept(*this);
        Monitor *monf = mon;
        f->g->accept(*this);
        Monitor *mong = mon;
        mon = new SinceMonitor(input_reader, input_reader->open_handle(), 
                             monf, mong, f->from, f->to);
    }

MonitorVisitor handles:
- BoolFormula → NonTempMonitor
- AtomFormula → NonTempMonitor  
- PrevFormula → PrevMonitor (metric past operator)
- SinceFormula → SinceMonitor (metric past operator)
- UntilFormula → UntilMonitor (metric future operator)
- NegFormula, AndFormula, OrFormula → Recursive composition
- BwFormula, FwFormula → Regex-based dynamic monitors

4.3 DEFINE MonitorState STRUCTURE
----------------------------------
LOCATION: After Monitor forward declaration, before Event struct

ADD:
    class Monitor;  // Forward declaration
    
    // Wrapper for Monitor instance with metadata
    struct MonitorState {
        Monitor* monitor;           // The actual monitor instance
        timestamp first_seen;        // When this binding first appeared
        timestamp last_updated;      // Last time this monitor was updated
        bool current_verdict;        // Cached verdict from last evaluation
        
        // Default constructor
        MonitorState() 
            : monitor(nullptr), first_seen(0), last_updated(0), current_verdict(false) {}
        
        // Constructor with monitor and timestamp
        explicit MonitorState(Monitor* mon, timestamp ts) 
            : monitor(mon), first_seen(ts), last_updated(ts), current_verdict(false) {}
        
        // Destructor - owns the monitor
        ~MonitorState() {
            if (monitor != nullptr) {
                delete monitor;
            }
        }
        
        // Copy constructor - clone the monitor
        MonitorState(const MonitorState& other) 
            : monitor(other.monitor ? other.monitor->clone() : nullptr),
              first_seen(other.first_seen),
              last_updated(other.last_updated),
              current_verdict(other.current_verdict) {}
        
        // Assignment operator
        MonitorState& operator=(const MonitorState& other) {
            if (this != &other) {
                if (monitor != nullptr) delete monitor;
                monitor = other.monitor ? other.monitor->clone() : nullptr;
                first_seen = other.first_seen;
                last_updated = other.last_updated;
                current_verdict = other.current_verdict;
            }
            return *this;
        }
    };
    
    struct Event {

EXPLANATION:
MonitorState wraps a Monitor* with metadata:
- monitor: Points to the actual Monitor instance for this tuple binding
- first_seen: Timestamp when this tuple binding first appeared in the log
- last_updated: Last timestamp when we updated this monitor
- current_verdict: Cached result from last monitor evaluation
- Copy/assignment properly clone monitors for independent state

    void insert_into_pdt(int pred_id, const vector<string>& args, Formula* formula_template) {
        // Get or create PDT for this predicate
        auto it = predicate_pdts.find(pred_id);
        if (it == predicate_pdts.end()) {
            // Initialize with empty leaf (no monitor yet)
            predicate_pdts[pred_id] = Pdt::Leaf<MonitorState>(MonitorState());
        }

        if (base_formula == nullptr) {
            base_formula = formula_template;
        }

        predicate_pdts[pred_id] = insert_tuple_recursive(
            predicate_pdts[pred_id], args, 0, formula_template
        );
    }

        auto it = predicate_pdts.find(pred_id);
        if (it == predicate_pdts.end()) {
            return false;  // No tuples for this predicate
        }
        return match_pattern_recursive(it->second, pattern, 0);
    }

private:
    // Recursive helper to insert tuple into PDT
    Pdt::PdtT<MonitorState> insert_tuple_recursive(
        const Pdt::PdtT<MonitorState>& current_pdt,
        const vector<string>& tuple,
        size_t arg_index,
        Formula* formula_template
    ) {
        // BASE CASE: All arguments processed, create leaf with monitor
        if (arg_index >= tuple.size()) {
            // Check if we're updating an existing leaf or creating new one
            if (Pdt::isleaf(current_pdt)) {
                const auto& existing_leaf = std::get<Pdt::Leaf<MonitorState>>(current_pdt);
                if (existing_leaf.value.monitor != nullptr) {
                    // Tuple already exists, just update timestamp
                    MonitorState updated_state = existing_leaf.value;
                    updated_state.last_updated = ts;
                    return Pdt::Leaf<MonitorState>(updated_state);
                }
            }
            
            // Create new monitor for this binding using MonitorVisitor
            MonitorVisitor visitor(reader);
            formula_template->accept(visitor);
            Monitor* new_monitor = visitor.get_mon();
            
            MonitorState new_state(new_monitor, ts);
            return Pdt::Leaf<MonitorState>(new_state);
        }
        
        // RECURSIVE CASE: Process current argument
        const string& current_value = tuple[arg_index];
        string var_name = "x" + std::to_string(arg_index);
        
        // If current PDT is a leaf, convert to node
        if (Pdt::isleaf(current_pdt)) {
            Part::PartT<Pdt::PdtT<MonitorState>> new_part;
            
            // Create singleton set for current value
            Setc::SetT value_set = Part::singleton_set(Dom::Str(current_value));
            Setc value_setc = Setc(value_set);
            
            // Recursively process rest of tuple
            Pdt::PdtT<MonitorState> sub_pdt = insert_tuple_recursive(
                Pdt::Leaf<MonitorState>(MonitorState()),
                tuple,
                arg_index + 1,
                formula_template
            );
            
            new_part.emplace_back(value_setc, sub_pdt);
            return Pdt::Node<MonitorState>(var_name, new_part);
        }
        
        // If current PDT is already a node
        if (Pdt::isnode(current_pdt)) {
            auto node = std::get<Pdt::Node<MonitorState>>(current_pdt);
            Part::PartT<Pdt::PdtT<MonitorState>> updated_part = node.part;
            
            // Look for existing partition containing this value
            bool found = false;
            for (auto& [setc, sub_pdt] : updated_part) {
                if (Setc::member(Dom::Str(current_value), setc)) {
                    // Found existing partition, recursively insert
                    sub_pdt = insert_tuple_recursive(sub_pdt, tuple, arg_index + 1, formula_template);
                    found = true;
                    break;
                }
            }
            
            if (!found) {
                // Create new partition for this value
                Setc::SetT value_set = Part::singleton_set(Dom::Str(current_value));
                Setc value_setc = Setc(value_set);
                
                Pdt::PdtT<MonitorState> sub_pdt = insert_tuple_recursive(
                    Pdt::Leaf<MonitorState>(MonitorState()),
                    tuple,
                    arg_index + 1,
                    formula_template
                );
                
                updated_part.emplace_back(value_setc, sub_pdt);
            }
            
            return Pdt::Node<MonitorState>(node.x, updated_part);
        }
        
        throw std::runtime_error("Invalid PDT state");
    }
    
    // Step all monitors in a PDT recursively
    void step_pdt_monitors(Pdt::PdtT<MonitorState>& pdt) {
        if (Pdt::isleaf(pdt)) {
            auto& leaf = std::get<Pdt::Leaf<MonitorState>>(pdt);
            if (leaf.value.monitor != nullptr) {
                try {
                    BooleanVerdict v = leaf.value.monitor->step();
                    leaf.value.current_verdict = (v.b == TRUE);
                    leaf.value.last_updated = ts;
                } catch (const EOL& e) {
                    // Handle end of log
                }
            }
            return;
        }
        
        if (Pdt::isnode(pdt)) {
            auto& node = std::get<Pdt::Node<MonitorState>>(pdt);
            for (auto& [setc, sub_pdt] : node.part) {
                step_pdt_monitors(sub_pdt);
            }
        }
    }
    
    // Recursive helper to match pattern against PDT and evaluate monitors
    bool match_pattern_recursive(
        const Pdt::PdtT<MonitorState>& pdt,
        const vector<string>& pattern,
        size_t arg_index
    ) const {
        // BASE CASE: Reached leaf, evaluate monitor
        if (Pdt::isleaf(pdt)) {
            const auto& leaf = std::get<Pdt::Leaf<MonitorState>>(pdt);
            
            // If no monitor exists, tuple doesn't satisfy
            if (leaf.value.monitor == nullptr) {
                return false;
            }
            
            // Return cached verdict from last monitor step
            return leaf.value.current_verdict;
        }
        
        // RECURSIVE CASE: Node
        if (Pdt::isnode(pdt)) {
            if (arg_index >= pattern.size()) {
                // Pattern exhausted but still have levels - check if any leaf is true
                return check_any_monitor_true(pdt);
            }
            
            const auto& node = std::get<Pdt::Node<MonitorState>>(pdt);
            const string& pattern_term = pattern[arg_index];
            
            // Check if pattern term is a variable (lowercase single letter)
            bool is_var = (pattern_term.length() == 1 && 
                          pattern_term[0] >= 'a' && pattern_term[0] <= 'z');
            
            // Check each partition
            for (const auto& [setc, sub_pdt] : node.part) {
                bool matches = false;
                
                if (is_var) {
                    // Variable: matches any value in this partition
                    matches = true;
                } else {
                    // Constant: check if value is in partition set
                    Dom pattern_value = Dom::Str(pattern_term);
                    matches = Setc::member(pattern_value, setc);
                }
                
                if (matches) {
                    // Recursively check rest of pattern
                    if (match_pattern_recursive(sub_pdt, pattern, arg_index + 1)) {
                        return true;
                    }
                }
            }
            
            return false;  // No partition matched
        }
        
        return false;
    }
    
    // Check if any monitor in PDT has true verdict
    bool check_any_monitor_true(const Pdt::PdtT<MonitorState>& pdt) const {
        if (Pdt::isleaf(pdt)) {
            const auto& leaf = std::get<Pdt::Leaf<MonitorState>>(pdt);
            return leaf.value.monitor != nullptr && leaf.value.current_verdict;
        }
        
        if (Pdt::isnode(pdt)) {
            const auto& node = std::get<Pdt::Node<MonitorState>>(pdt);
            for (const auto& [setc, sub_pdt] : node.part) {
                if (check_any_monitor_true(sub_pdt)) {
                    return true;
                }
            }
        }
        
        return false;
    }
    
    // Debug helper to print PDT structure
    void print_pdt_recursive(const Pdt::PdtT<MonitorState>& pdt, int depth) const {
        string indent(depth * 2, ' ');
        
        if (Pdt::isleaf(pdt)) {
            const auto& leaf = std::get<Pdt::Leaf<MonitorState>>(pdt);
            std::cout << indent << "Leaf(";
            if (leaf.value.monitor != nullptr) {
                std::cout << "monitor=" << leaf.value.monitor 
                         << ", verdict=" << (leaf.value.current_verdict ? "true" : "false")
                         << ", first_seen=" << leaf.value.first_seen;
            } else {
                std::cout << "no monitor";
            }
            std::cout << ")" << std::endl;
            return;
        }
        
        if (Pdt::isnode(pdt)) {
            const auto& node = std::get<Pdt::Node<MonitorState>>(pdt);
            std::cout << indent << "Node(var=" << node.x << ")" << std::endl;
            
            for (const auto& [setc, sub_pdt] : node.part) {
                std::cout << indent << "  Values: ";
                bool first = true;
                for (const auto& val : setc.to_set()) {
                    if (!first) std::cout << ", ";
                    std::cout << Dom::to_string(val);
                    first = false;
                }
                std::cout << std::endl;
                print_pdt_recursive(sub_pdt, depth + 2);
            }
            return;
        }
    }
};

EXPLANATION:

    }

   - Could optimize with persistent data structures
   - Consider lazy evaluation strategies for metric intervals

   - Only supports sequential arg0, arg1, arg2 ordering
   - Doesn't handle variable reordering (p(x,y) vs p(y,x))

9.2 KEY ALGORITHMS
------------------
1. TUPLE INSERTION (insert_tuple_recursive)
   - Recursively partitions by each argument
   - Creates nodes for internal variables
   - Creates monitors at leaves using MonitorVisitor
   - Handles existing vs new tuples

2. PATTERN MATCHING (match_pattern_recursive)
   - Variables match any value
   - Constants require exact match
   - Returns true if any matching monitor has true verdict

3. MONITOR STEPPING (step_pdt_monitors)
   - Walks entire PDT tree
   - Calls step() on each leaf monitor
   - Updates cached verdicts

4. MONITOR CREATION (via MonitorVisitor)
   - Visitor pattern creates appropriate monitor type
   - Fresh Event handle for each monitor
   - Recursive construction for nested formulas
